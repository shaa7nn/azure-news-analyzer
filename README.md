# 🧠 Azure AI News Analyzer

An AI-powered news analysis web app built using **Python**, **Streamlit**, and **Azure AI Language Service**.

## 🚀 Features

- 📰 News Article Analysis
- 👤 Person Detection
- 🏢 Organization Detection
- 🌍 Location & Country Extraction
- 📅 Important Date Detection
- 😊 Sentiment Analysis
- 🔑 Key Phrase Extraction
- 📊 Interactive Dashboard

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Azure AI Language Service
- Pandas
- Plotly

---

## ⚙️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/azure-news-analyzer.git

cd azure-news-analyzer

pip install -r requirements.txt
```

---

## ▶️ Run App

```bash
streamlit run projecttt.py 
```

---

## ☁️ Azure Setup

Create an Azure AI Language resource from:

```text
https://portal.azure.com
```

Copy:
- Endpoint
- Key

Paste them into the application sidebar.
